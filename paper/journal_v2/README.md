# Journal manuscript (telemetry study), prepared to the Elsevier guide for authors

## Submission files

| File | Elsevier item |
|---|---|
| `build/manuscript.docx` | manuscript, editable Word: abstract ≤ 250 words, 6 keywords, Inspec codes, numbered sections, appendices A and B with Eqs. (A.1), (A.2), (B.1), declarations, author–year references |
| `build/highlights.docx` | highlights, separate editable file (3–5 bullets, ≤ 85 characters each) |
| `artwork/Graphical_abstract.tiff` (`.pdf`, `.png`) | graphical abstract, separate file, drawn at 13 cm width (≥ 1328 px wide) |
| `artwork/Figure_1.pdf` … `Figure_4.pdf` | figures as separate vector files with embedded fonts (`.png`, 300 dpi, are used inside the Word file) |
| `build/Supplementary_Material.docx` | supplementary material (Tables S1…, Figs. S1–S2; `artwork/Figure_S*.pdf`) |
| `build/manuscript.pdf` | review copy (LibreOffice export; Liberation Serif substitutes for Times New Roman) |

Other build outputs: `build/manuscript.md` (every number substituted), `build/used_keys.json` (every evidence key used, with value and source).

## Sources and tools

| Path | What it is |
|---|---|
| `src/paper.md`, `src/highlights.md` | sources; numbers appear only as `{{evidence.key}}` placeholders |
| `src/supplementary.md`, `src/supplementary_labels.json` | generated by `tools/make_supplementary.py`; the manuscript cites supplementary items as `[S:label]` |
| `refs_journal.bib`, `tools/elsevier-harvard.csl` | checked bibliography (published versions, DOIs, LTWA abbreviations, `[dataset]` and `[software]` entries) and the Elsevier Harvard style with four commented patches |
| `tools/crossref.yaml` | caption and reference formats ("Fig. 1.", "Table 1.", "Eq. (1)") |
| `tools/make_paper_figures.py`, `tools/make_graphical_abstract.py`, `tools/make_paper_diagrams.py` | artwork |
| `tools/render_paper.py` | build; aborts on a placeholder without evidence, an unknown supplementary label, an unfilled `[[...]]` marker, or an abstract or keyword list outside the journal limits. `--draft` shows missing items as `[pending]` for layout checks |
| `VENUES.md` | candidate Scopus-indexed journals (verify Scopus status and quartile before submitting) |

Numbers come from `thesis/evidence/evidence.json`, the same evidence file as the thesis.

## Before submission (authors)

- Fill in authors, affiliations, the CRediT statement, funding and competing interests, and review the generative-AI declaration so that it describes your actual use.
- Deposit the derived data (scores, alarms, result files, evidence file) on Zenodo and replace "[DOI to be added]"; archive the code release that contains `scripts/posthoc_v2/` and cite its DOI in the `[software]` reference.
- Check the Inspec codes against the current classification (they were confirmed on archived IET pages from 2013–2019) and drop them if the target journal does not ask for them.
- Choose the TC-CAD version DOI if the journal prefers a version over the concept DOI.
- Apply the target journal's template once the journal is chosen.
